# Gerar documentação de projeto

Objetivo: Leia e entenda o projeto dessa pasta e crie uma documentação extensiva, incluindo:

- Documentação de escopo, descrevendo o projeto (use, expanda, melhore o conteúdo do readme.md), objetivos, mecanismos, plataformas,frameworks, banco de dados, requisitos e tecnologias envolvidas.
- Documentação do código: crie cabeçalhos descritivos nos arquivos do código implementado ignore arquivos de configuração de ambiente e arquivos de fluxo do framework (flutter). Documente classes e funções. Use a notação "dartdoc", "javadoc", "jsdoc" ou equivalente para garantir integração com ambientes de desenvolvimento (vscode, android studio, xcode, etc)
- Crie um arquivo monolito (html) contendo a documentação de escopo, a documentação técnica do código, agrupada por unidade lógica de referência ou por funcionalidade (em casos de apis e utilitários). Certifique-se de incluir recurso de busca rápida (apertando "/") e TOC. Se precisar de esquemas ou ilustrações, crie com SVG. O layout do arquivo de documentação deve ser responsivo (de mobile até fullhd), temas claro e escuro, tipografia moderna sem serifas. Crie uma folha de estilo específica para impressão, que inclua cabeçalho e rodapé, contagem de páginas, controle de linhas órfãns e viuvas.
