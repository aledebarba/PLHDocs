# Requisitos do Sistema - SIGEC

## Requisitos Funcionais (RF)
| ID | Descrição |
| :--- | :--- |
| RF-01 | O sistema deve permitir que o morador realize autenticação. |
| RF-02 | O sistema deve permitir consultar os espaços comuns disponíveis. |
| RF-03 | O sistema deve permitir visualizar a disponibilidade de um espaço por data e horário. |
| RF-04 | O sistema deve permitir solicitar uma reserva. |
| RF-05 | O sistema deve permitir ao morador consultar suas reservas. |
| RF-06 | O sistema deve permitir o cancelamento de uma reserva quando as regras forem atendidas. |
| RF-07 | O administrador deve poder aprovar ou recusar solicitações. |
| RF-08 | O administrador deve poder cadastrar, alterar e inativar moradores. |
| RF-09 | O administrador deve poder cadastrar e alterar espaços comuns. |
| RF-10 | O sistema deve manter o histórico das reservas. |

## Requisitos Não Funcionais (RNF)
| ID | Descrição |
| :--- | :--- |
| RNF-01 | O acesso às funcionalidades administrativas deve ser protegido por autenticação. |
| RNF-02 | O sistema deve possuir controle de acesso de acordo com o perfil do usuário. |
| RNF-03 | O sistema deve apresentar interface de fácil utilização para moradores e administradores. |
| RNF-04 | As operações de consulta de disponibilidade devem apresentar resposta adequada para o uso cotidiano. |
| RNF-05 | Os dados das reservas devem ser armazenados de forma consistente. |
| RNF-06 | O sistema deve possuir mecanismo de backup dos dados. |
